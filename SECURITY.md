# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately:

1. **Do not open a public GitHub issue.**
2. Send an email to the maintainers or open a private GitHub Security Advisory.
3. Include details of the vulnerability, reproduction steps, and potential impact.

We will review reports promptly and publish patches in a timely manner.
