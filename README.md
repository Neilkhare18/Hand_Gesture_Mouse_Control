# Hand_Gesture_Mouse_Control
🖱️ High-performance touchless mouse controller in Python using Google MediaPipe Tasks, OpenCV, and Windows Win32 API at 60 FPS. Features jitter-free One-Euro filtering, digital camera zoom, anti-slip click locking, smooth scrolling, and robust drag-and-drop with hysteresis. 100% offline, ultra-low latency (&lt;2ms), and portable across any PC.
